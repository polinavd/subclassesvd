# Гримнир и Лайонисс для Foundry

Версия 0.2.0. 24 подкласса из предоставленных книг по правилам 2024. Названия и правила на английском; меню на русском. В комплекте способности, отдельные действия и атаки, заклинания, спутники и иконки.

## Установка и обновление

Откройте **Модули → Установить модуль** и вставьте Manifest URL:

```text
https://raw.githubusercontent.com/polinavd/subclassesvd/main/module.json
```

Включите **Grimnir & Lyonesse — Subclasses (2024)** в мире. Для следующих версий используйте кнопку обновления модуля, затем перезапускайте мир.

Для ручной установки распакуйте [ZIP](https://raw.githubusercontent.com/polinavd/subclassesvd/main/dist/grimnir-lyonesse.zip) в `Data/modules/`. Итоговый путь: `Data/modules/grimnir-lyonesse/module.json`.

## Персонаж

1. Добавьте соответствующий базовый класс 2024 и установите его уровень.
2. Перетащите подкласс из компендиума Гримнира или Лайонисса на лист.
3. Подтвердите выдачу способностей и выбор владений. Связанные действия, оружие и заклинания появляются отдельными карточками.
4. Используйте эти карточки из листа персонажа. Выбор оружия для дополнительной атаки показывает уже имеющееся оружие персонажа. Primal Arm сначала требует выбора формы.
5. При повышении уровня класса подтвердите новые способности.

После обновления с 0.1.0 ведущая открывает мир: существующие фичи модуля получают новые описания, иконки и доступные по уровню карточки. Импортированный макрос **Управление подклассом → Обновить карточки персонажа** позволяет запустить обновление повторно. Повторный запуск не добавляет дубли и сохраняет потраченные использования.

Компендиумы: **Гримнир**, **Лайонисс**, **Заклинания**, **Спутники и формы**, **Управление и проверка**. Выбираемые заклинания True Believer и Binding Savant добавляются через выбор; для дополнительных Summon spells можно использовать установленные в мире компендиумы.

## Совместимость

Целевая версия: Foundry 13.351 и D&D5e 5.2.3. Манифест допускает Foundry 14, но работа в этой версии пока не проверена. D&D5e 6.x требует отдельной адаптации.

## Исходники

[Репозиторий](https://github.com/polinavd/subclassesvd). Редактируемые документы: `source/`; скрипты: `scripts/`. Пересборка: Node.js 22.16+, `npm ci`, `npm run package`. Упакованные базы и установочный ZIP проверяются при сборке.
